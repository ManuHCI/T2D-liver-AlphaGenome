How to read this tree. Level 0 = 108 fine-mapped T2D variants (FinnGen R12 and GCST90475667; PIP ≥ 0.2). Level 1 = the nearest protein-coding gene to each variant, kept only when AlphaGenome (HepG2, liver, hepatocyte tracks) is confident about the direction (|quantile| ≥ 0.99): 91 genes. This hybrid rule was chosen because, on 328 causal GTEx liver eQTLs, the nearest gene identified the target gene more often than AlphaGenome's top gene (62% vs 42%), while confident AlphaGenome directions were correct 82.5% of the time. Levels 2–3+ come from CollecTRI (TF → target) and OmniPath (signalling) restricted to liver-expressed genes (GTEx TPM ≥ 1), with literature corrections (HNF4A → ABCG5/ABCG8 activating; LPA → LPAR2 removed). Validation status. Levels 0–1 are benchmarked. Levels 2+ did not validate against diabetic-liver expression (GSE23343, GSE15653), Open Targets gene sets, or FinnGen genetic direction (concordance 53% vs 50% shuffled, p = 0.39); no node passed FDR < 0.1. ★ nodes are exploratory hypotheses only. Push values are model scores, not percentages.
